## Verification

Phase 6 package verification must confirm:

- Setup flow is portable.
- Documentation uses relative paths.
- No private infrastructure paths are exposed.
- No tokens, keys, or private credentials are included.
- Buyer compliance burden is stated.
- Production warnings are clear.
- Build and tests still pass after documentation updates.
