# Zebepay Buyer Demo Checklist

Use this checklist to help buyers quickly understand what Zebepay is and what they are buying.

## Buyer Must See

- Product name: Zebepay Payment Gateway
- One-line offer: developed payment gateway platform for private commercial sale
- Main dashboard screenshot
- Wallet/account workflow screenshot
- Transaction list screenshot
- Admin operations screenshot
- Buyer package contents
- Pricing language: flexible/custom price
- Contact or purchase request method

## Demo Video Structure

1. Open with Zebepay name and payment gateway positioning.
2. Show the dashboard.
3. Show wallet or account workflow.
4. Show transaction/transfer records.
5. Show admin/operator controls.
6. Explain what the buyer receives.
7. Explain that pricing is flexible and agreed per buyer.
8. End with the purchase/contact instruction.

## Buyer Questions To Answer

- What is Zebepay?
- Is it a payment gateway?
- Is it already developed?
- Is it for sale?
- What do I receive after buying?
- Can it be customized?
- Can I get setup support?
- How much does it cost?
- How do I request access?

## Commercial Notes

- Do not expose the private GitHub repo publicly.
- Present Zebepay only as a private commercial product.
- Use controlled private delivery after payment or approval.
- Keep all buyer-facing instructions portable.
- Do not promise banking, regulatory, or licensed financial status unless separately approved.
- Keep the sales message clear: Zebepay is a developed payment gateway software product available for private commercial sale.
