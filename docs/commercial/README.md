# Zebepay Commercial Buyer Pack

This folder contains the buyer-facing commercial material for Zebepay.

Use these files to show buyers that Zebepay is a developed payment gateway product available for private commercial sale.

## Files

- `BUYER_SALES_PAGE.md` - public sales page copy and product positioning
- `BUYER_DEMO_CHECKLIST.md` - demo, screenshot, and buyer education checklist
- `PRICING_AND_OFFER.md` - flexible pricing and offer structure

## Positioning

Zebepay should be presented as:

> A developed payment gateway platform available for private commercial sale, with flexible pricing based on source access, setup help, deployment support, or white-label customization.

## Important Rules

- Keep the GitHub repo private.
- Present Zebepay only as a private commercial product.
- Use portable public-facing documentation only.
- Use controlled private delivery after payment or approval.
- Do not promise regulated banking/payment licensing unless separately approved.
