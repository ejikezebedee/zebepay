## Buyer Positioning

Paystack is positioned as hosted payment processing. Zebepay is positioned
as source-code ownership of a Nigerian fintech infrastructure foundation.

Use the sales line:

Do not buy Zebepay if you only need a simple payment link. Use Paystack.
Buy Zebepay if you want to own, customize, and launch a Nigerian fintech
infrastructure foundation with your own brand, providers, compliance process,
and operating model.

## Controlled Access Model

The recommended buyer path is:

1. Public product page or direct outreach.
2. Buyer qualification.
3. Evaluation-only private GitHub access or sanitized source preview.
4. Tier selection and license acceptance.
5. Payment confirmation.
6. Full source delivery and setup clarification within the purchased support
   scope.
