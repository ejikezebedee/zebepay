# Standard Chartered NG Benchmark

## Purpose

Zebepay should use Standard Chartered NG as a quality benchmark, not as a source to copy.

We will not copy Standard Chartered code, brand, logos, colors, exact layouts, screenshots, or protected assets. We will use public feature patterns and banking-grade experience standards as reference.

## Public Benchmark Sources

- Standard Chartered Nigeria SC Mobile page: https://www.sc.com/ng/banking/sc-mobile/
- Standard Chartered Nigeria online banking page: https://www.sc.com/ng/banking/online/
- SC Mobile Nigeria app listings on public app stores

## Experience Standards To Emulate

- Clean mobile-first banking flows
- Account overview as the default home experience
- Clear movement of money: own account, same-bank, other-bank, bills, airtime/data
- Account-opening and account-upgrade logic
- Profile-update capabilities
- Statement and transfer-history access
- Card management expectations
- Customer communication mailbox/notification pattern
- Trustworthy, calm, low-noise interface
- Strong confirmation screens and receipts

## Zebepay Translation

### Customer Home

- Total available balance
- Wallet/account cards
- Recent transactions
- Quick actions
- Pending requests
- Important notices

### Move Money

- Internal transfer
- Bank transfer request
- Beneficiary list
- Scheduled transfer-ready structure
- Fee and limit preview
- Confirmation
- Receipt

### Manage Account

- Profile
- KYC status
- Account tier
- Statements
- Devices/sessions
- Notification preferences
- Support mailbox

### Service Requests

- Account statement request
- Reference-letter-ready request structure
- Card request placeholder
- Cheque-book/bank-draft placeholders for licensed buyers
- Dispute/reversal request

## Design Direction

Zebepay should feel professional, Nigerian, and bank-grade:

- Dense but readable dashboard
- Restrained color palette
- Clear hierarchy
- Icon-led quick actions
- Strong status labels
- No decorative gimmicks
- No fake “toy bank” energy

The design should be original and branded for Zebepay.
