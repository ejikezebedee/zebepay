# Zebepay License Terms Draft

This is a commercial license draft for buyer review. Final license wording should be approved by the seller before public sale.

## Suggested Commercial License

The buyer may:

- Use the source code to build one internal product or one client product.
- Modify the code for that product.
- Deploy the modified product under the buyer's approved infrastructure.
- Connect licensed providers and production services.

The buyer may not:

- Resell the original source-code package as a template, starter kit, or competing product.
- Share the source-code package publicly.
- Claim Zebepay provides a banking license or regulated financial authorization.
- Use the package for unlawful financial activity.
- Remove required compliance and security warnings from buyer-facing documentation.

## Compliance Boundary

The buyer is fully responsible for:

- Banking, fintech, or payment licensing.
- KYC/AML compliance.
- Provider contracts.
- Legal review.
- Production security review.
- Customer support and operational risk management.
- Live launch approval.

## Warranty Position

Suggested wording:

"Zebepay is provided as source-code software for evaluation, customization, and development. It is not legal, financial, compliance, or security advice. The seller does not guarantee regulatory approval, provider acceptance, or production suitability without buyer-led review and implementation."

## Finalization Required

Before public sale, the seller should confirm:

- Exact license type.
- Number of allowed projects per purchase.
- Refund policy.
- Support scope.
- Update policy.
- Whether agency/client work is allowed under the base package or a higher tier.
