# Zebepay Demo Video Script

## Goal

Show buyers that Zebepay is not a shallow fintech screen pack. It includes customer banking, admin operations, API workflows, ledger logic, risk controls, and buyer documentation.

## Suggested Runtime

5 to 8 minutes.

## Script

### 1. Opening

"Zebepay is a Nigerian banking and wallet infrastructure foundation for fintech founders, agencies, licensed operators, and development teams."

"It is software only. Buyers handle licensing, compliance, regulated providers, security review, and live payment rail approval."

### 2. Customer App

Show:

- Customer dashboard.
- NGN/kobo balance display.
- KYC tier indicator.
- Trusted device signal.
- Quick actions.
- Beneficiaries.
- Prepared transfer.
- Security alerts.

Narration:

"The customer experience is built around account visibility, transfer preparation, beneficiary management, statements, KYC status, and security alerts."

### 3. Admin Console

Show:

- Operations console.
- KYC review metrics.
- Risk holds.
- Transaction supervision.
- Risk gate.
- Audit trail.

Narration:

"The admin console is where operations, compliance, support, and audit teams supervise the banking workflow."

### 4. API Walkthrough

Show API examples:

- Health check.
- Customer login.
- OTP challenge.
- Trusted device registration.
- Transfer creation.
- Transfer review queue.
- Transfer release.
- Notification listing.

Narration:

"The backend includes real domain boundaries: auth, KYC, transfers, ledger posting, risk review, notifications, account controls, and audit events."

### 5. Ledger And Risk

Show:

- Successful transfer creates a debit ledger entry.
- Reversal creates a credit ledger entry.
- High-risk transfer enters manual review instead of posting immediately.

Narration:

"Money movement is controlled through idempotency, ledger posting, and review states. Risky transfers can be held before funds move."

### 6. Buyer Documentation

Show:

- Setup guide.
- Deployment guide.
- API reference.
- Troubleshooting.
- Buyer support guide.
- GitHub issue templates.
- Release checklist.
- Sales page copy.

Narration:

"The package includes buyer-facing documentation so a purchaser can evaluate, run, customize, and plan production integration."

"Buyers also get a GitHub-native support path for pre-sale questions, approved
setup support, and security routing."

### 7. Close

"Zebepay gives buyers a serious Nigerian fintech foundation. It is not a banking license and not a finished regulated institution by itself. It is a commercial source-code platform designed to shorten the build path for teams that will connect their own licensed providers and compliance process."
