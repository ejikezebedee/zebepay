# Zebepay Support

## Buyer Contact Path

Use GitHub as the default buyer contact channel.

- Pre-sale or evaluation questions: open a GitHub discussion or use the
  `Pre-sale question` issue template if discussions are not enabled.
- Paid buyer setup support: open a private-repository issue with the
  `Buyer support request` template.
- Security concerns: follow `SECURITY.md`.
- Custom implementation, provider integration, deployment, compliance workflow,
  or production hardening: request a paid implementation scope.

If the repository is private, buyers must first receive approved access through
the buyer access process in `release/BUYER_ACCESS_SOP.md`.

## What To Include

For setup or package support, include:

- Purchased tier or evaluation status.
- Node.js version.
- Operating system.
- Command run.
- Error output.
- App or service affected.
- Whether dependencies were installed with `npm install --include=dev`.

## Support Boundary

Included support is limited to download/access clarification, setup guide
navigation, first-run troubleshooting, and documentation clarification within
the approved support window.

Zebepay support does not include legal advice, banking/payment licensing,
production security certification, regulated provider approval, live payment
operations, custom development, or hosted infrastructure management unless a
separate paid agreement is approved.
