# Zebepay Buyer Production Warning

Zebepay is a private commercial source-code foundation for Nigerian wallet,
banking, and payment-product development. It is software source code only.

Zebepay is not:

- A licensed bank.
- A licensed payment processor.
- A CBN-approved operator.
- A NIBSS-connected provider.
- A legal opinion.
- A compliance certification.
- A production security certification.
- A live regulated financial service.

Before any live regulated use, the buyer must complete and document:

- Banking, payment, and data-protection licensing review.
- Regulated provider onboarding.
- KYC/AML provider integration.
- Production password, PIN, and session hardening.
- Webhook signature verification for all live provider callbacks.
- Independent application and infrastructure security audit.
- Legal and compliance review.
- Infrastructure hardening, backups, monitoring, and incident-response setup.
- Final management approval for go-live.

The buyer must not represent Zebepay as live banking infrastructure, regulated
payment processing, CBN/NIBSS-approved technology, or certified financial
software until the buyer independently obtains all required approvals,
integrations, reviews, and certifications.
