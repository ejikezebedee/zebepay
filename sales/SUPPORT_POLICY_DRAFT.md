# Zebepay Support Policy Draft

## Status

Draft for MD approval before public sale.

## Included Support

Included buyer support may cover:

- GitHub repository or release access clarification.
- Download or repository access issues.
- Package file clarification.
- Setup guide clarification.
- First-run troubleshooting.
- Documentation navigation.
- Explanation of where provider integrations should be added.
- Clarification of known production gaps.

## Excluded Support

Included buyer support does not cover:

- Banking or payment licensing.
- Legal advice.
- Compliance certification.
- Production security certification.
- Regulated provider approval.
- Custom feature development.
- Hosted infrastructure management.
- Production incident response.
- Live payment-rail operations.
- Buyer team training beyond package documentation.

## Suggested Support Window

- Tier 1 - Builder License: 7 days of setup clarification.
- Tier 2 - Commercial Launch License: 14 days of setup clarification.
- Tier 3 - Enterprise / Investor-Grade Package: 30 days of setup clarification.
- Custom implementation: separate paid agreement.

## Response Target

Suggested target: respond within 2 business days for included support requests.

## Required Buyer Information For Support

Ask the buyer to include:

- Purchased package/tier.
- Node.js version.
- Operating system.
- Command they ran.
- Error output.
- App or service affected.
- Whether dependencies were freshly installed.

## GitHub Intake

Use `SUPPORT.md` as the public buyer support entry point.

- Pre-sale or evaluation questions should use GitHub Discussions when enabled,
  or the `Pre-sale question` issue template.
- Paid setup support should use the private repository `Buyer support request`
  issue template.
- Security concerns should follow `SECURITY.md`.

Disable blank public issues until the final support policy is approved.

## Escalation To Paid Work

Move the request to paid customization when the buyer asks for:

- New features.
- Provider integration implementation.
- Production deployment.
- Database migration beyond the included schema.
- Compliance workflow customization.
- Branding or UI redesign.
- Multi-tenant architecture.
- Security hardening implementation.

## Approval Gate

This policy is a draft until MD approves final support scope, duration, price, and refund terms.
