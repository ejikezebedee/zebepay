# Zebepay Commercial Terms Draft

## Status

Approval-ready draft. Final terms require MD approval before public sale.

## Recommended License Position

Use a single-project commercial source-code license for the base package.

The buyer may:

- Use the code for one internal product or one client product.
- Modify the code for that approved product.
- Deploy the modified product under the buyer's approved infrastructure.
- Connect licensed providers and production services.

The buyer may not:

- Resell the original source-code package.
- Publish the source-code package publicly.
- Repackage the code as a competing template, starter kit, or marketplace product.
- Claim the package includes banking licensing, compliance certification, payment-rail approval, or production security certification.
- Use the package for unlawful financial activity.

## Recommended Refund Policy

Because Zebepay is a digital source-code package, refunds should be limited to:

- Duplicate purchase.
- Incorrect file delivery.
- Download or access failure that cannot be resolved.

Refunds should not cover:

- Buyer misunderstanding of licensing responsibilities.
- Buyer misunderstanding of regulated provider requirements.
- Buyer expectation that the product is immediately live-production ready.
- Customization difficulty.
- Rejection by a bank, regulator, provider, investor, or client.

## Recommended Support Scope

Included support should cover:

- Access or download issues.
- Setup documentation clarification.
- First-run troubleshooting.
- Documentation navigation.
- Guidance on where custom provider integrations should be added.

Included support should not cover:

- Custom feature development.
- Production deployment.
- Legal advice.
- Compliance certification.
- Production security certification.
- Provider approval.
- Live payment operations.

## Recommended Delivery Method

Preferred delivery method: private GitHub repository access for approved buyers.

Fallback delivery method: packaged source archive if marketplace delivery requires a downloadable file.

## Required Buyer Notice

Every buyer-facing page should state:

Zebepay is source-code software only. It does not include a banking license, regulated provider approval, legal advice, compliance certification, production security certification, direct payment-rail access, or managed production service.

## Approval Gate

Before public sale, MD must approve:

- License terms.
- Package tiers.
- Price points.
- Refund policy.
- Support scope.
- Delivery method.
- Buyer access process.
- Repository visibility.
- Public product page.
