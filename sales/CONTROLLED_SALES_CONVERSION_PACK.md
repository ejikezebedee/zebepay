production security audit, and customize the code before going live.

## FAQ Prompts

### Is this a licensed bank or payment processor?

No. It is source-code software only.

### Does it include live NIBSS, Paystack, Monnify, or Flutterwave credentials?

No. Buyers must connect their own approved providers and complete regulated
go-live checks.

### Can it be used for an investor demo?

Yes, after local setup and buyer-specific customization.

### Can it go live immediately?

No. Production use requires provider integrations, security review, compliance
review, infrastructure hardening, monitoring, backup/restore planning, and
regulated approval where applicable.

### How is support handled?

Approved buyer support is routed through GitHub using `SUPPORT.md` and the
included issue templates. Custom implementation, provider integration,
deployment, legal review, or production hardening requires a separate paid
scope.
