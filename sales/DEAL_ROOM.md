# Zebepay Deal Room

## Purpose

This file explains how buyers can find the product, examine the code, and ask
for a deal without exposing unrestricted source code.

## Public Discovery Channels

Use these channels to attract buyers:

- Public GitHub repository summary or private repository preview page.
- private sales listing.
- LinkedIn founder/operator posts.
- Direct outreach to fintech founders, software agencies, cooperatives,
  microfinance operators, and Nigerian payment consultants.
- Investor/demo video showing the customer app, admin app, API docs, ledger
  workflow, and provider adapter concept.

## Buyer Funnel

1. Buyer sees the public product page.
2. Buyer reads the compliance boundary and pricing tiers.
3. Buyer submits an inquiry.
4. We qualify the buyer by use case, company, budget, and urgency.
5. Qualified buyer receives a private code-review invitation or controlled
   source archive preview.
6. Buyer reviews the code and documentation.
7. Buyer selects the tier and accepts commercial license terms.
8. Payment is confirmed.
9. Full source access or package archive is delivered.
10. Buyer receives setup guidance within the purchased support scope.

## Code Review Access

Preferred code-review method:

- Private GitHub repository access.
- Time-limited evaluation access.
- No redistribution rights.
- No production deployment rights before purchase.
- Evaluation covered by the proprietary license notice in `LICENSE`.

Fallback method:

- Sanitized source archive.
- No `node_modules/`.
- No local environment files.
- No logs or internal files.
- Include only product code, docs, sales files, release files, and examples.

## Deal Request Form Fields

Ask every serious buyer for:

- Name.
- Company.
- Country.
- Email or verified contact channel.
- Intended use case.
- Buyer type: founder, agency, licensed operator, investor, developer, or
  enterprise team.
- Preferred tier: Builder, Commercial Launch, or Enterprise.
- Whether they need private-label/client usage rights.
- Whether they already have licensing, regulated partners, or provider
  relationships.
- Desired timeline.

## Approved Pricing

### Tier 1 - Builder License: EUR 5,000

For founders or developer teams that want the full source package for one
approved product.

### Tier 2 - Commercial Launch License: EUR 10,000

For buyers who want stronger launch support, commercial handoff, and one
approved internal or client deployment path.

### Tier 3 - Enterprise / Investor-Grade Package: EUR 20,000

For serious operators, agencies, or investor-backed teams that need deeper
handoff, private-label readiness, architecture walkthroughs, and priority
commercial support.

## Qualification Script

Zebepay is not a Paystack account. It is a source-code infrastructure
foundation for buyers who want to own and customize a Nigerian fintech product.

If you only need payment links, Paystack is the better choice. If you want your
own wallet, admin dashboard, API, ledger workflow, provider adapter layer,
compliance-ready structure, and branded fintech foundation, Zebepay is the
right conversation.

## Non-Negotiable Boundaries

- Do not sell it as CBN-licensed software.
- Do not promise live payment processing rights.
- Do not grant full source access before buyer qualification.
- Do not remove compliance or security warnings.
- Do not promise production launch without buyer's provider, legal,
  compliance, security, and infrastructure work.
